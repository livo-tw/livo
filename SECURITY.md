# 安全性問題回報 / Security policy

請不要用公開 issue 回報安全性問題。

- 首選：在 GitHub 用 [私下回報弱點](https://github.com/livo-tw/livo/security/advisories/new)。
- 或寄信到 service@livo-tw.com，主旨寫「LIVO security」。

請附上受影響的部署方式（Cloudflare、Docker 或兩者）、重現步驟，以及你看到的影響。修正釋出之前請先不要公開細節。我們會盡快回覆並告知處理進度。

目前只維護 `main` 分支的最新版本。

---

Please do not report security problems in public issues. Use GitHub's [private vulnerability reporting](https://github.com/livo-tw/livo/security/advisories/new), or email service@livo-tw.com with "LIVO security" in the subject. Include the affected deployment (Cloudflare, Docker or both), steps to reproduce and the impact you observed, and keep the details private until a fix is released. Only the latest `main` is maintained.
